# FPL Agent

Welcome to the FPL Agent project! This application leverages a large language model (LLM) to provide insights and help you make smarter player picks for Fantasy Premier League (FPL).

When you're paying 12.7m for Salah, you expect him to get at least one assist and a goal every week, right? 😅 But FPL doesn’t always play fair. To tackle this challenge, we created the FPL Agent, an AI-driven tool designed to enhance your FPL strategy. 

### Features

- **Insight Gathering**: Utilizes Tavily to gather the latest insights on player form, fixtures, and performance.
- **Data Analysis**: Pulls player statistics directly from the FPL API, providing a detailed breakdown based on real, up-to-date data—not just gut feeling.

Is it perfect? Not yet. The project is a work in progress and still requires some prompt tuning.

## Prerequisites

- OpenAI API key
